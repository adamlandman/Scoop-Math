# Sophie's Scoop Math 🍦

A 4th-grade math game where every correct answer earns an ice cream scoop, and the faster you answer, the better the topping.

## How to play

Open `index.html` in any web browser. It's a single file with no install and no build step.

Each round has 10 problems. A timer counts down on each one, and the topping on your cone changes as time runs out:

| Topping | When you get it | Points |
|---|---|---|
| 🍬 Candy Jackpot (super rare) | Answer super fast | 100 |
| 🌈 Rainbow Sprinkles | Answer quickly | 50 |
| 🍫 Hot Fudge | Take your time | 30 |
| Raisins | Last 5 seconds | 10 |
| 💧 Melted | Time runs out | 0 |

Wrong answers can be retried, but the clock keeps running.

## Math modes

- **Mix of everything**
- **Multiplying**: facts to 12×12, 2-digit × 1-digit, missing factors
- **Dividing & fractions**: division facts, fraction of a number
- **Add, subtract & round**: 3-digit addition and subtraction, rounding to tens and hundreds
- **Word problems**: short ice-cream-themed story problems

Works with the on-screen keypad (good for tablets) or a keyboard (digits, Backspace, Enter).
